# Changelog

## 1.0.0

Initial release (in preparation).

- Compact VM details on Enter, with a shared hostname, resource summary, metadata
  grid, and browser/SSH buttons; no duplicate SSH/web address blocks.
- Live human-readable creation age beside the VM name.
- Confirmed restart, pause/resume, and copy operations with admin checks and
  bounded background commands.
- E opens the exe.dev REPL in a new floating terminal.
- Row-wide click action: SSH by default, configurable to browser or details.
- Persistent S/B shortcut guide with no per-row action buttons.
- Details track VM identity across refreshes and preserve the filtered list on return.

- Native Omarchy Quattro bar widget for exe.dev virtual machines.
- Tag-grouped VM list with browser and SSH actions.
- Keyboard-driven, case-insensitive fuzzy search with ranked, flat results.
- Bounded background SSH refreshes and last-successful-list fallback.
- Theme-aware popout with scrolling and access-aware action buttons.
