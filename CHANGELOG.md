# Changelog

## 1.0.0

Initial release.

- Native Omarchy Quattro bar widget for exe.dev virtual machines.
- Tag-grouped VM list with browser and SSH actions.
- Keyboard-driven, case-insensitive fuzzy search with ranked, flat results.
- Bounded background SSH refreshes and last-successful-list fallback.
- Theme-aware popout with scrolling and access-aware action buttons.
